## 紹介

この拡張機能は手作業を減らし、Megascans 素材を Library にすばやく追加するためのものです。

初回実行前にログイン状態を確認してください。ログイン後は次の2つの機能を使えます。

1. **一括追加**：素材一覧をスキャンしながら Library に追加します。
2. **素材ライブラリをスキャン**：素材一覧をスキャンし、Library への追加は行いません。

**バッチ間の待機時間**（推奨300 ms以上）と**バッチ処理数**（推奨3～10件）を設定できます。件数が多いほど、待機時間を長くすることをおすすめします。

設定の目安：

| バッチ処理数 | 待機時間 |
|---|---|
| 3～5件 | 300 ms |
| 6～10件 | 500～800 ms |

これらは追加速度が速すぎることによるレート制限のリスクを減らすための参考値です。制限が発生すると、拡張機能は待機時間を自動的に延長し、入力欄と状態表示を更新します。一時停止して手動で待機時間を長くしてから再開することもできます。待機時間はバッチ内の全処理が完了してから数えます。モデルファイルのダウンロードは行いません。

問題が発生した場合は「**LOG**」をエクスポートし、**thstudio3419@pm.me** へメールでお送りください。

## インストール方法

1. 私たちの GitHub ページにアクセスし、拡張機能の **QiMegaClaim @THS.zip** をダウンロードしてください。
2. ダウンロードした ZIP ファイルを展開し、Google Chrome の拡張機能設定ページ `chrome://extensions/` を開きます。
3. 右上の「**デベロッパー モード**」を有効にします。
4. 左上の「**パッケージ化されていない拡張機能を読み込む**」をクリックします。
5. 展開した「**QiMegaClaim @THS**」フォルダーを選択し、確定します。
6. ブラウザーの拡張機能欄にある QiMegaClaim アイコンを開き、「**Quixel Megascans を開く**」ボタンを押すと起動できます！

## 使用方法

ログインを確認したら「**一括追加**」を押してください。その他の設定は、下部の操作バー右上にある「**！**」の説明を参照してください。

更新時は拡張機能管理ページで再読み込みし、Fab ページを更新してください。削除して再インストールする必要はありません。
