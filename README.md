## 介紹

此擴展用於節省人工操作，快速將 Megascans 素材加入 Library。

首次執行請先確認登入狀態。登入後可使用兩種功能：

1. **一鍵入庫**：邊掃描素材庫，邊進行入庫作業。
2. **僅掃描素材庫**：單純掃描素材庫，不進行入庫。

可設定**批次間隔**（建議 300ms 起）與**每批處理數量**（建議 3～10 個）。數量越多，建議拉長間隔時間。

設定參考：

| 每批處理數量 | 批次間隔 |
|---|---|
| 3～5 個 | 300ms |
| 6～10 個 | 500～800ms |

此設定用於避免入庫速度過快而觸發官方限流，以上數值為參考值。若被限制，腳本會自動延長批次間隔，並更新欄位與狀態提示；也可暫停後手動提高間隔，再繼續執行。批次間隔是整批處理完成後的等待時間；本擴展不下載模型檔案。

若遇到異常問題，請先匯出「LOG」，並寄信至 **thstudio3419@pm.me**。

## 安裝方式

1. 請先到我們的 GitHub 頁面，下載腳本 **QiMegaClaim @THS.zip** 檔案。
2. 下載完成後，先解壓縮，然後打開 Google Chrome 的擴充功能設定頁面：`chrome://extensions/`。
3. 開啟右上角的「**開發人員模式**」按鈕。
4. 選擇左上角的「**載入未封裝項目**」按鈕。
5. 選擇解壓縮後的「**QiMegaClaim @THS**」資料夾，按下確認。
6. 開啟瀏覽器擴充功能欄位的 QiMegaClaim 圖標，點擊「**開啟 Quixel Megascans**」按鈕即可執行！

## 使用方式

確認已登入後，直接按下「**一鍵入庫**」。其他設定說明可參考操作橫欄右上角的「**！**」按鈕。

更新版本時，在擴充功能管理頁面按重新載入，再刷新 Fab 網頁即可，不必移除重裝。
